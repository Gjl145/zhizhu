### ★ 关键判断：这套课程的内容 ≠ 用户要的玩法

Chaos 的能力可以分成三层：

| 层 | 能力 | 我们的玩法需要吗 |
|---|---|---|
| **几何破碎** | Voronoi 切割、集群断裂、层级、断裂内部面 | ❌ 不需要 |

## 二、Unity 侧能不能做（逐项查证，非印象）

### 结论：能。Unity 没有内置 GeometryCollection，但**本玩法不需要**。

| Chaos 能力 | Unity 2022.3 对应 | 差距 |
|---|---|---|
| 实时 Voronoi 破碎 | 无内置。需 RayFire（$190，5折 $95）或自研 | ★★★ 大 |
| 集群断裂 Cluster Fracture | 无内置。第三方有（Fracture / Quick Destruction）| ★★☆ 中 |
| 结构连通性图 Connectivity | 无内置。需自己写父子依附图 | ★★☆ 中 |
| **锚定场 Anchor Field** | ★ **`Rigidbody.isKinematic` 切换** | ★ 很小 |
| 碎片刚体物理 | ★★ **原生就是**（PhysX，比 Chaos 更成熟）| ★ 无差距 |
| 碎片碰撞伤害 | ★★ `OnCollisionEnter` + `collision.impulse` | ★ 无差距 |
| **拽倒整面墙** | ★★ **`ConfigurableJoint` / `HingeJoint`** | ★ 无差距 |
| Niagara 联动破碎事件 | ★★ VFX Graph 需手搓上一帧位置 | ★★ UE 省 2~3 天 |

★ **Unity 在「刚体物理」这一层是持平甚至更强的**（PhysX vs Chaos）。
差距全在「几何破碎」—— 而那正是我们不需要的。

### 行业事实（重要，别被视频带偏）
1. **最常用的破坏实现不是实时破碎，是「预破碎」（Pre-fracture）**。
   离线用 Blender Cell Fracture / Houdini 切好，运行时只是「换成一个碎块预制体 + 给刚体」。
   —— 我们连 Blender 都不用，**墙体是我们自己生成的规则长方体，用 ProBuilder / 代码切块即可**。
2. **《漫威蜘蛛侠》(2018) 本身没有体素破坏。** 官方战斗是
   「掀井盖砸人 / 拉敌人 / 环境互动投掷」—— **正是预破碎 + 刚体**，
   不是实时 Voronoi。教程原文：「周边可拉动的物品会有按键提示显示」。
   ★ **我们的玩法就是照官方设计抄的，方向天然正确。**
3. 建筑不悬浮的做法 = **连接性图（Connectivity Graph）**：
   碎块失去所有接地支撑 → 开重力 → 塌。
   Unity 里可用「父子依附记录 + 逐层检查支撑」实现，约 100 行。

## 三、★ 结论

**能做，而且成本远低于「迁到 UE 学 Chaos」。**

- 迁 UE 重写：`SilkParkourController` 2698 行 + `SilkBuilder` 892 行
  = **19 天**（30 行/小时实测速率）
- 做这个最小战斗系统：**约 7~18 小时**新代码，**不迁引擎、不换工具**

**但也要说清楚「做不到什么」：**
- ❌ 打不出 Chaos 那种「在墙上炸个洞、裂纹实时扩散」的效果
- ❌ 不做 GeometryCollection 就没法任意切任意形状
- ✅ **但「拉下一面墙砸死人」完全不需要这些**

## 四、最小可行方案（MVP）

### 4.1 交互设计（★ 不新增任何按键）

用户原话约束：「不准再新增加按键」。本方案**零新增按键**：

```
左键发射丝线 → 命中墙体 → 拉住 → 按现有「左Shift 冲刺」拉拽
            → 墙体脱开 → 砸中敌人 → 敌人受伤
```
丝线的「左键发射 / 右键松开」完全复用现有键位。
冲刺拉拽复用 `左Shift`。

### 4.2 三层实现（按性价比排序）

**第 1 层：整面墙 hinge 脱落**（★ 首选，半天）
- 墙 = 1 个 Rigidbody + 1 个 `ConfigurableJoint`（锚在顶部）
- 丝线拉力 > `breakForce` → `joint` 断开 → 整面墙平着掉落
- 砸人：`OnCollisionEnter` 里 `collision.impulse.magnitude` → 伤害
- **这是「拉下墙体砸人」的最小字面实现**，不需要任何碎块

**第 2 层：墙体分块（预破碎）**（★ 推荐，1~2 天）
- 墙在生成时切成 `2×3` 或 `3×4` 块（我们本来就是规则长方体，切块是几行代码）
- 每块一个 BoxCollider + Rigidbody，**初始 `isKinematic = true`**
- 丝线拉动某块 → 该块及其上方块转 `isKinematic = false`（= AnchorField 等价物）
- 这就是「拉垮一角 → 连锁坍塌」，视觉上比整面倒更真实

**第 3 层：Voronoi 真实破碎**（❌ 本项目不做）
- 需 RayFire（$190，5 折 $95）或自研 Voronoi 切割 + 内部面生成
- 成本 ≫ 收益，且**当前关卡是规则长方体，切块已足够**

### 4.3 需要写的文件

| 文件 | 行数量级 | 职责 |
|---|---|---|
| `Assets/Silk/DestructibleWall.cs` | ~180 | 分块管理、支撑图、断裂判定 |
| `Assets/Silk/EnemyHealth.cs` | ~80 | 血量、受击反馈、死亡 |
| `Assets/Silk/SilkAnchorBody.cs` | ~60 | 丝线锚点从「固定 Transform」扩展到「可拉住刚体」 |
| 测试关卡 `Assets/ceshi_break.unity` | — | 一面墙 + 3 个敌人 |

### ★★ 最大风险点（必须提前说）

**`SilkChain` 现在是「锚点固定 + 球为末端」的约束求解**，
丝线只对**末端（球）**施力。要拉住一块可破坏墙，
需要新增「末端锚在刚体上并施力」的模式。

这是唯一需要碰核心文件的地方，风险等级：
- `SilkChain.cs`（1079 行）—— 中等风险，**必须用 Edit 精确改，不许脚本替换**
- 改完必跑 `check_unity_errors.py` + `selfcheck.py` + `check_regressions.py`

### ★★ 第二个风险：重力 98 的量级

本项目重力是 **10 倍地球**（`SilkPhysics.Gravity = 98`，对齐 Fristrom）。
墙从 3 格高（1.5 m）落下：

```
v = √(2gH) = √(2 × 98 × 3) ≈ 24.2 格/s
```

★ **比现实快约 1.6 倍**。所以：
- 伤害数值必须用 **`collision.impulse.magnitude / rigidbody.mass`（等效速度变化）**
  而不是直接用 `impulse.magnitude` —— 否则碎块大小不同伤害差 100 倍
- 敌人被砸飞的速度也会偏快，需要单独调敌人质量
- **不要照抄任何现实世界的伤害公式**，必须实算

## 五、决策建议

| 方案 | 建议 |
|---|---|
| 只做第 1 层（整面墙脱落） | ✅ **先做这个验证手感**，半天 |
| 做第 1+2 层（分块坍塌）| ✅ 手感对了再上 |
| 第 3 层 Voronoi | ❌ 不做 |
| 迁到 UE 学 Chaos | ❌ **净亏 7~24 天** |

**推荐路径：先做第 1 层（半天）→ 实测「拉墙砸人」好不好玩 → 再决定要不要第 2 层。**

理由：这一层的成本极低（~200 行），且能立刻回答
「这个玩法到底好不好玩」这个唯一真正未知的问题。
如果第 1 层就不好玩，第 2 层也不会救。

## 六、★ 用户确认的需求范围（2026-10-09 原话）

> 「几何破碎我要的，相关的我也要，但是我使用的到没有那么难的，
> 我要实现的包括预破碎和刚体的。外加一点点的能直接拉碎墙体什么的，
> 然后甩出去砸人。不过不能实现就算了」

### 拆成三档（难度递增）

| 档 | 内容 | 难度 | 是否本次目标 |
|---|---|---|---|
| **A 必做** | 预破碎（墙体切块）+ 刚体物理 | ★ 低 | ✅ |
| **A 必做** | 投掷环境物体砸人（掀井盖式）| ★ 低 | ✅ |
| **B 想做** | 丝线拉住环境物体（官方「拉敌人」同款）| ★★ 中 | ✅ |
| **C 尽量** | 一点点实时拉碎墙体（不打洞、不扩散裂纹）| ★★ 中 | ⭕ 能做就做 |
| **D 不做** | Chaos 级实时 Voronoi 扩散 / 集群断裂 / Niagara 联动 | ★★★★ 高 | ❌ |

★ 「一点点能直接拉碎墙体」的最小实现：
丝线拉住的**那一块**碎块转 dynamic，其余不动。
= Anchor Field 的最小形态，不需要任何 Voronoi 算法。

### ★ 官方战斗设计对照（用户认可的兜底方案）
《漫威蜘蛛侠》(2018)：掀井盖砸人 / 用蛛网拉敌人 / 投掷环境物体。
= A 档 + B 档，**已在范围内**。若 C 档做不出来，A+B 就是完整的官方级战斗手感。
