# 蜘蛛假骨骼 —— 怎么看到它（2026-10-09 第 8 版）

## 第0 步：运行哪个场景？★ 这就是之前失败的原因

**运行 `Assets/ceshi.unity`**（就是你自己的测试场景）。

不是 `Assets/Scenes/SampleScene.unity`。SampleScene 里只有一个空物体 bossbattle
挂 SilkBuilder，**没有任何相机、没有任何网格、没有任何碰撞体** —— 跑它是必然什么都看不到。

如果你现在打开的是 SampleScene：Project（项目）窗口里双击 `Assets/cesheshi.unity` 切换过去。

---

## 第 1 步：让 Unity 重新编译（★ 最容易被忽略）

我刚改了代码，但你可能跑的还是旧的 dll。

1. 如果现在在 Play 状态 → 先按播放键**停止**
2. 菜单资源（Assets）→ 刷新（Refresh）  —— 或直接 `Ctrl + R`
3. 等Unity 右下角转圈结束（几秒）
4. 看底部 Console：**必须是 0 个红色错误**才能继续

> 为什么强调这一步：我改完三处修复后，`Assembly-CSharp.dll` 的时间还是 **12:02**，
> 而代码是 **12:07** —— 你跑的那一轮跑的是修复前的旧 dll。
> 怎么确认：`Library/ScriptAssemblies/Assembly-CSharp.dll` 的修改时间应该比
> `Assets/Silk/SilkSpiderTestStage.cs` 的**新**。

## 第 2 步：Play，然后按 Tab

按播放键（▶，或 `Ctrl + P`）。**不要**去检查器勾任何开关 —— 组件全是运行时自动挂的，检查器里根本看不到。

进入游戏后，**画面左上角会出现一行白色文字**，比如：

```
蜘蛛假骨骼 自检
模式: FreeFly（未按 Tab）
球: 不存在
腿: 8 / 8条
相机↔球: 0.0 格
★ 现在按 Tab 切到 Parkour 才会建球
```

**按一下 `Tab`** → 模式变成 `Parkour（球已建）`，球出现在地板上。

## 第 3 步：读 HUD，一次定位断在哪一环

不用看Console、不用猜。把左上角那几行**念给我听**即可：

| HUD 显示 | 说明什么 |
|---|---|
| `模式: FreeFly（未按 Tab）` | 正常，按 Tab 即可 |
| `模式: Parkour（球已建）` 但**画面全空** | 相机问题 → 检查 Console 有没有 `[SpiderTest] 场景里已有相机` |
| `球: 存在` 但**球是个小黑点** | 落点问题 → 检查有没有 `已把球心落点钉在地板` 这条日志 |
| `腿: 0 / 8条` | 蜘蛛没建成→ 检查有没有 `[SpiderBody]` 报错 |
| `腿: 8 / 8条` 但看不到线 | 材质问题 → Console 会有 `[SpiderLeg] 找不到可用着色器` |
| **完全没有 HUD 文字** | 测试场根本没建 → Console 里搜 `[SpiderTest]` |

## 常见追问

**Q：为什么不让我去检查器勾开关？**
第一版说明确实让你去勾三个开关（Enable Input / Show Debug / Enable Legs），
证明完全无效 —— 组件是运行时挂在临时物体上的，检查器里根本不存在。

**Q：以前说「运行 SampleScene」，为什么错了？**
我一直在分析 `SampleScene.unity`，但你实际打开的是 `ceshi.unity`
（`Library/LastSceneManagerSetup.txt` 是铁证）。
`ceshi.unity` 里从来就没有 SilkBuilder，也没有 MonoBehaviour。
现在的代码已经三级兜底，两种场景都能跑。

**Q：测试场会删掉我的 Cube / Sphere 吗？**
不会。代码里有显式白名单，你的 Cube、Sphere、Main Camera、Directional Light 都被跳过。
（场景里那个 Sphere 在 `(41152, 166.5, 114044)`，离原点 12 万格，
本来就在远裁剪面 1000 之外，永远渲染不出来 —— 那是无关的旧物体。）

**Q：还是看不到，接下来怎么办？**
把 Console 里 `[SpiderTest]` / `[SpiderMove]` / `[SpiderBody]` 开头的所有行
+ HUD 的四行文字发给我。有这些我不需要猜，能直接定位。
