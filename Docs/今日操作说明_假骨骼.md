## 为什么要按 Tab（不是可以省略的步骤）

这个项目有两个世界，用 `Tab` 切换：

| 世界 | 作用 | 相机 | 球 |
|---|---|---|---|
| **FreeFly**（启动时的默认） | 编辑器世界、织网| 自由飞行 | **不建球** |
| **Parkour**（按 Tab 切过去） | 跑酷世界 | 第三人称跟随 | 建球 + 长 8 条腿 |

控制器代码里写死了这一句（`SilkBuilder.cs: 4475`）：

```csharp
if (mode == SilkControlMode.Parkour)
{
    transform.position = startPosition;
    CreateVisual();        // ★ 球只在这里建
}
```

`mode` 的初值是 `FreeFly` → **不按 Tab，屏幕上不会有球，也不会有腿。**
这是项目原有的设计（FreeFly 下不该出现球），不是 bug。

## 本次修掉的三个「啥也看不到」的根因

之前以为是**一个**问题（循环依赖），实际是**三个独立的**，缺一个都看不见东西。

### 根因 1 · 循环依赖：测试场要靠控制器挂，控制器又靠测试场创建

```
场景里只有 bossbattle，挂 SilkBuilder，没有 SilkParkourController
  → AutoAttach 遍历 SilkParkourController[] 得到空数组
  → 循环体一次都不执行
  → SilkSpiderTestStage 永远挂不上
  → 相机 / 控制器 / 球全都没建
```

**修法**：把 `AutoAttach` 拆成三步，**先认 SilkBuilder**（它一定在场景里，是唯一确定的入口）：
① 遍历 `SilkBuilder[]` 挂上 `SilkSpiderTestStage` → 它建相机/控制器/球
② 再回头遍历 `SilkParkourController[]`（此时已经有了）挂运动组件
③ 起一个常驻 watcher，每 0.5 秒补挂 Tab 切换后新建的控制器

### 根因 2 · 场景里根本没有相机

`SampleScene.unity` 里Camera / Light / MeshRenderer / Collider 的数量**全是 0**，
只有一个 `bossbattle`。相机原本是 `SilkBuilder.Build()` 运行时new 的，
但那个方法开头有幂等守卫：

```csharp
var existing = Object.FindObjectOfType<SilkBuilder>();
if (existing != null) { ...; return; }   // ★ 场景里已有 bossbattle → 整个跳过
```

**修法**：新增 `EnsureCameraAndLight()`，幂等补齐相机 + 光源，
在 `Build()` 建几何**之前**就调用（否则建完那帧画面还是黑的）。

### 根因 3 ★ 最隐蔽 · 几何**有 Collider 但没有 Mesh**

```csharp
var go = new GameObject(name);           // ★ 空物体，没有 MeshFilter/MeshRenderer
go.transform.localScale = size;
var box = go.AddComponent<BoxCollider>(); // 碰撞体正常
var mr = go.GetComponent<MeshRenderer>();// ★ 永远返回 null → 整段着色器代码被跳过
if (mr != null) { ... }                   //   永远不执行
```

**墙、台阶、横梁、内角全部有碰撞体、能挡住球，但一个像素都看不见。**
即使相机和控制器都正常，画面依然只有测试场以外的东西。

**修法**：改用 `GameObject.CreatePrimitive(PrimitiveType.Cube)` ——
自带网格 + 渲染器 + 碰撞体，尺寸直接配 `localScale`（Cube 网格是单位立方）。

### 附带修的三处

| 问题 | 修法 |
|---|---|
| `comp.Awake()` 会报 CS0122 | 删掉。嵌套类的 private 方法外层无权访问，且 AddComponent 本来就会自动调 |
| 腿可能完全不可见 | LineRenderer 显式给材质（`Sprites/Default` → `Unlit/Color` → `Diffuse` 三级兜底）|
| 只有一个腹部空物体、没有身体 | 新建扁椭球腹部（`CreatePrimitive(Sphere)`），Collider 立即销毁以免干扰射线 |
