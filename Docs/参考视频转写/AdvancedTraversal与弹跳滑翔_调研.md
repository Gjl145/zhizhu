## 一、结论先行：网盘那个插件**下载了也用不了**

### Advanced Traversal System v1.12.7z 的真实情况

| 项 | 事实 | 出处 |
|---|---|---|
| 引擎 | **仅 Unreal Engine**（蓝图项目）| 官方 Patreon 页：「The project is based on Blueprints」|
| 前置依赖 | **ALS（Advanced Locomotion System**，LongmireLocomotion 制作）| 同上 |
| 文件格式 | `.uasset` / `.umap`（UE 专有二进制）| UE 项目结构 |
| 美术资产 | 另售 Patreon 档，FBX + **UE4 mannequin 骨架** | 同上 |
| 官方渠道 | Patreon `MD6_Products` 付费订阅 | 同上 |
| **Unity 版本** | ★ **不存在，作者从未出Unity 版** | 全网检索无|

★ **为什么用不了**：`.uasset` 是 UE 的专有序列化格式，Unity 无法读取。
就算解压了，Unity 里打开只会是「无法识别的文件」。
**这跟「参考源码」是两回事** —— 蓝图逻辑存在二进制里，看不到。

### ★ 要读它的蓝图，前置条件是装 UE5
我们**没装 UE5**（引擎选型已定为不换，见 `引擎选型评估_2026-10-08.md`，
下载 50GB≈15 小时）。所以「拆包看蓝图」这条路被双重堵死。

★ 结论：**网盘那个不用下载。** 下载了也只是一堆 Unity 打不开的二进制文件。

## 三、附带发现：一个真正相关的 Unity 资源（供以后考虑）

检索时找到 **Modular Grappling Hook System**（Unity 版）：

- Pull / Hold / **Swing** 三种模式 +绳长收放
- `GrappleMotor` + `GrappleTargeter` + `GrappleConfig`（ScriptableObject 调参）
- 视觉绳索用 `LineRenderer`（★ 与我们现有实现一致）
- 明确标注适用「**Spider-Man style traversal**」
- Unity 2022.3 LTS 起支持

★ 这是检索 Advanced Traversal System 时**偶然找到**的，不是我主动搜的。
它的功能列表（Pull/Hold/Swing +收放绳）**恰好覆盖我们 `SilkChain` 已有的能力**，
说明我们的功能选型没跑偏。

★ 但**不建议现在买**：我们的 `SilkChain` 已经写了 1079 行，功能比它全
（我们还有固化节点、收绳增速、墙体解算）。
买它是「用别人的小的换自己的大的」，方向错了。
