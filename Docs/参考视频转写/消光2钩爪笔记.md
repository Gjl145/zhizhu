## 一、钩爪的物理形态（从画面逐帧观察）

### 1.1 钩爪本体
画面中可见：钩爪是**三爪式**（三个弯钩），连接一段
**编织纹理的粗绳**（绿色/橄榄色，螺旋缠绕纹路）。

→ 绳索的表现很关键：即使玩家不动，绳子也是**自然下垂的弧线**，
  不是绷直的直线。这与我们的 `catenarySag` / `slackScale` 方向一致。

### 1.2 绳索与建筑的关系
在多个画面里能看到绳索**挂在建筑外的桁架/吊臂/灯杆**上 ——
游戏世界里专门有一批「可钩挂点」（黄色标记点在 HUD 上可见）。

→ 对应我们的：墙面锚点（`AnchorPoint`）。
  差别是我们的锚点是规则网格（间距 8 格），消光2 的是**散布在建筑上的可用点**。
  **视觉表现**：消光2 的可钩点在远处有**明显的黄色高亮**，
  玩家一眼能看出「那个能钩」—— 这正是我们缺的「目标可见性」。

### 1.3 摆荡姿态
- 玩家**单手握绳**，身体被绳索牵引
- 绳索长度看起来是**发射瞬间确定的**（钩住后不再变长）
- 摆荡过程中玩家可以**沿绳索上下滑动**（爬绳）

## 二、机制要点（官方资料交叉验证）

来源：游侠网/ 07073 等攻略站的官方操作说明 + 视频 2 的设计原则

### 2.1 操作序列
> PS/Xbox：**在跳跃过程中**按 L2/LT 释放抓钩，
> 「将其作为绳索摆动」

→ **关键：钩爪只能在空中（跳跃中）发射**，不是地面随便发射。
  我们的 `FireAtAnchor` 目前是地面空中都能发，条件比它宽松 ——
  这可能是「感觉不对」的原因之一。

### 2.2 二连抓（连续摆荡）
官方攻略在教学关（VNC 大厦）明确写道：
> 「首先用钩爪抓住吊灯荡到对面。然后连续利用钩爪前往指定位置。
> **这里需要二连抓**。」

→ **连续摆荡**是官方教学关的核心训练内容。
  即：松手后立刻再抓下一个点，速度不中断。

### 2.3 引导设计（印证视频 2 的原则）
同一段攻略提到教学关里的引导手法：
> 「顺着**黄色的印迹**斜向下滑」
> 「在下滑的过程中**找准时机**用钩爪抓到挂钩荡过去」
> 「利用**吊灯**做平台进行跳跃」

→ 黄色印迹 = 地面/墙面的视觉路径指引（与我们做的护栏同一思路）。
  而「找准时机」说明**时机是玩家要学的核心**，不是自动判定。

## 三、与我们实现的差距（这是重点）

| 维度 | 消逝之光2 | 我们当前 | 差距性质 |
|---|---|---|---|
| 钩爪发射时机 | **只能在跳跃中** | 地面/空中都能发 | 条件太宽松 |
| 连续摆荡（二连抓） | 教学关核心训练 | 松手后可再抓，但节奏靠玩家 | 机制有了，教学没做 |
| 可钩点的视觉标识 | 远处**黄色高亮**可见 | 黄色小球，近处才看得清 | **可发现性不足** |
| 绳索下垂 | 自然弧线 | 有悬链线垂度 | 已接近 |
| 沿绳索上下滑动 | 可爬绳 | 无 | 缺失 |
| 钩住后绳长 | 发射瞬间固定 | 固定 | 一致 ✓ |
| 体力/消耗 | 有耐力限制 | 无 | 后期考虑 |

### 最值得优先补的一条：**钩爪只在跳跃中可发射**

理由：这是官方明确的操作契约，也是「摆荡节奏」的基础 ——
它让玩家的每次发射都对应一次**主动的跳跃决策**，
而不是站在平台上随手发射。

对应到我们的实现：`FireAtAnchor` / `PickBestAnchor` 应加一个
「必须不在地面上」的前置条件（就像消光2 那样）。
但要注意我们左键既用于「地面发射」又用于「空中抓线」，
需要重新规划键位分工。

### 第二条：**可钩点的远距离可见性**

消光2 用**黄色高亮**让玩家在远处就规划好路线。
我们刚做的 `UpdateAimIndicator`（指引线 + 目标标记）方向是对的，
但还缺「远距离就能看到可钩点」这一层 ——
现在锚点是实体小球，远处几乎看不见。

参考做法：给锚点加**自发光 / 亮度随距离提升**的视觉，
或在高处/关键位置的锚点做特殊标记（对应视频 2 的「地标」原则）。
