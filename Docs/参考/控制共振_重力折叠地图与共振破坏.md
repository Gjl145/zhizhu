## 零、视频性质先说清

**这是评测视频，不是技术教程。** 539段转写里没有一句技术实现细节。
但它把「折叠地图」这件事描述得足够具体，而顺着游戏名能挖到真正有价值的技术资料。

### UP 主的结论（原话要点）

| 维度 | 评价 |
|---|---|
| 地图 | **Remedy 历年最好的地图**，曼哈顿被「折叠」成无数奇形怪状的样子 |
| 地图怎么来的 | **不是地编拼接，也不是生成**，是「巨量的人工去堆砌」，每个区域差异性极大 |
| 探索 | 四处穿梭、上下纵横、反复切换重力本身就是享受 |
| 支线 | 以 SCP 怪谈 / 都市传说为基底，几乎全部足量手工设计 |
| 战斗 | **最不好玩的部分**。技能树看着长，实际能用的 build 就那么几种 |
| Boss | 「Remedy 真的不会设计 Boss 战」，后期几乎只剩机制和场地切换 |
| 生理 | 3D 眩晕严重 + 饱和度极高（满屏红黑），UP 主第一次开色盲模式 |

>「这游戏的地图就像一个巨大的工艺品，每一个区域都有巨大的差异性，
> 每一个区域的核心探索逻辑也不同……这是工业流水线根本实现不了的东西。」

★ **注意这句**：「不是地编来拼接，或者说生成就能设计出来的东西，需要巨量的人工去堆砌」。
**折叠地图不是技术问题，是关卡设计工作量问题。** 后面第五节展开。

## 一、★ 重力切换：原视频里最有价值的技术描述

视频 110~180 秒讲的是重力异常（Gravity Anomalies），这是整个游戏的地基。

### 三层地图结构（逐步展开，不是开场就给）

| 层 | 描述 | 玩家的重力面 |
|---|---|---|
| **1. 表层都市** | 离开太古屋（Oldest House），眼前仍是高楼大厦，自主穿梭，像普通超能力都市游戏 | 只有 1 面 |
| **2. 折叠区** | 解开太古周围限制后到达异象化区域，**获得重力切换能力** | 2 面，能纵向往上跑，探索范围沿行到侧面和上面 |
| **3. 未知区（地下）** | 地图被切成**无数小空岛**，每岛布置一个可站面 | 无数面 |

### ★ 三个关键设计决策

**1. 默认重力面永远不变（像《重力异想世界》）**

>「无论你切换到哪一面，整张地图默认的重力面始终在原本的地方。」

**2. 游戏不提示哪一面是默认地面。** 这是刻意的——制造认知负担就是体验来源。

**3. ★ 玩家自己发明了认知技巧，而游戏没有引导**

UP 主自己的方法（这段本身就是设计洞察）：

>「无论我转到哪一面，我都只考虑我当前这一面发生的所有事情。
> 我不去考虑原本的默认重力方向，也不会考虑别的面是什么样的。
> **我只考虑我脚下是地板，上面是天花板。**」

→ 这说明游戏**故意不给参照系**，逼玩家自己建立局部坐标系。
→ ★ **可移植的设计**：多面世界的可用性不靠 UI 提示，靠「局部地板感」这一单一概念。

**4. 敌人也跟着切换重力方向。** 所以战斗是从各个位置、各个方向进行的。

**5. 未知区的平面「有可能是斜着的，有可能是倒着的」**

>「它已经不能完全按照你熟悉的 X 轴、Y 轴、Z 轴去理解，
> 你要不停地在这样一个立体地图里反复坠落。」

## 二、共振破坏系统（2019 年《控制》）—— ★ 真正的技术资料在这里

视频没讲，但Remedy 在 **GDC Summer** 上讲过程序化破坏。

### 2.1 ★ 核心原则：「granularity」（颗粒度）

Remedy首席 VFX 艺术家 **Johannes Richter**（GDC Summer 分享）：

>「你试图捕捉自然，因为自然不是被量化的。自然是一种连续体，
> 从非常大的物体一直到尘埃，直到非常薄的烟幕。
> 你总是想把这些都封装起来，在所有不同的尺度上创造出一条丰富的渐变。」

### 2.2 ★ 三层重叠表现（这是整个系统的骨架）

| 层 | 表现手段 | 数量级 |
|---|---|---|
| **1. 刚体模拟（RBD）** | 碎块、道具部件、环境块；环境本体是一个大静态 mesh 用来碰撞 | 少 |
| **2. 中间层** | mesh 粒子、刚体层级、材质贴花（decal） | 中 |
| **3. 纯粒子** | 粒子精灵、mesh 粒子（火星、火花、烟、火、碎片、砂砾） | 多 |

>「你从物体 → 到碎块 → 几乎到瓦砾。最后一层是纯粒子，
> 它们在填满那条渐变上起了很大作用。」

★ **为什么必须分三层**：越小的东西屏幕上越多，只能一层层往下掉表示方式。

### 2.3 ★ 为什么用程序化（而不是逐个做资产）—— ★ 真实原因

>「Control 的 VFX 团队**规模受限**。这意味着他们没法开始单独做上百个资产和道具。
> 但他们可以做的是：给这些物体赋上规则和元数据，来规定它们如何表现。」

★ **这是最诚实也最重要的一条**：程序化破坏不是为了技术炫技，
**是因为团队只有几个人，做不完几百个碎裂资产**。

### 2.4 ★ 实现方式：「procedural = 规则化地处理和解释世界数据」

>「procedural 是什么意思？它是**基于规则的数据处理和解释**。仅此而已。
> 你拿到一些数据和一些规则，然后应用规则、改变数据。这就是关键。」

具体做法：

```
美术模型 + 世界 = 数据
     ↓ 每个物体额外附加metadata：「我是什么做的」
布料 / 混凝土 / 植物 / 木头 / 金属 / 玻璃 / 电子设备
     ↓ 按材料套用规则
```

**规则实例（原文举的例子）**：

| 物体 | 被击中时发生什么 |
|---|---|
| 混凝土 | 碎成更小的混凝土块 → **然后生成粉尘** |
| 草 | 生成叶片碎片 |
| 金属管 | 生成水从洞里滴出→ 再加一个**弯曲贴花**（decal）来表现变形 |
| 布料沙发垫 | 按布料规则碎裂 |

>「我们创造了一套**有限的规则**来封装整个过程，
> 并确保每个物体——不管是木椅、植物、电脑还是混凝土柱——
> 都对《控制》世界里可能发生的一切有材料驱动的反应。」

★ **这与你项目里那套「参数全部接线、禁止死代码」的思路是同一个原则**：
规则是有限的，物体是海量的，靠**元数据 + 规则表**把复杂度从 O(物体数 × 规则数) 压下来。

## 三、《控制：共振》新增战斗系统（2026-09-24 发售）

### 3.1 近战武器「异变体 Aberrant」

**不是「在六把剑里选一把」，是「拼一套招式」。** 三类形态自由组合：

| 类别 | 作用 | 早期形态 |
|---|---|---|
| **Primary Form** | 普通攻击的基础 | Flurry（快双刃，高暴击）/ Slash（宽镰刀，群伤）/ Slice（高单体，背击加成） |
| **Secondary Form** | 特殊或重型攻击 | Crush（重击）/ Drill（持续伤害 + 上debuff）/ Extend（加距离） |
| **Combo Ender** | 终结特定连招 | 后期解锁 |

### 3.2 ★ 战斗闭环（这是设计上真正扎实的地方）

```
近战命中 → 恢复 Power
    → Power 用来放超能力
        → 超能力眩晕敌人
            → 敌人被处决
                → 处决给「Dominance」临时加近战伤害
                    → 继续压制
```

★ **血量也只能靠击杀敌人恢复**——战斗中没有嗑药。

**★ 没有格挡、没有招架（no blocking or parrying），唯一防御是闪避。**
Remedy 明确说：「这不是 Souls-like。」

### 3.3 敌人机制

- 杂兵**无限复活**，必须先击杀**带红圈标记的精英**才能推进（类似塞尔达血月）
- 精英还会「控制你的召唤物」——**专门克制召唤流**，而召唤流是Remedy 提前埋的坑位
- 技能洗点便宜，但**奇物（Artifact）改不了**，只能重新刷

### 3.4 三个成长系统（The Gap 里管理）

```
Abilities（超能力） × Weapon Upgrades（异变体形态） × Talents（天赋）
              + Artifacts（奇物，被动）
```
单周目**无法解锁全部** → 强制 build 多样性 + 推二周目。

### 3.5 ★ 地图结构定性

官方**刻意避开「开放世界」这个词**，用「large, open-ended space」。
实际是**多个大型、独立、高度可探索的「箱庭区域」**，每个区域手工打造并绑定叙事。

设计哲学（Kasurinen）：**"pulling" 玩家而非 "pushing" 玩家**。

## 四、技术规格（Northlight 引擎）

| 项 | 值 |
|---|---|
| 引擎 | Remedy 自研 **Northlight**（Alan Wake 2 / Quantum Break / Control 同源，重大升级） |
| 渲染 | **GPU-driven rendering**、mesh shaders、**单像素遮挡剔除**（single-pixel occlusion culling）|
| 目标 | 更远视距、更多同屏敌人、更重的破坏，同时稳定 60fps |
| 光追 | 路径追踪、**RTX Mega Geometry** |
| DLSS | **DLSS 4.5** 含 Dynamic Multi Frame Generation + Ray Reconstruction |
| 平台 | PS5 / Xbox Series X\|S / PC (Steam, Epic) / **Mac** / GeForce NOW 云 |

### ★ 2019 年《控制》的一条决定值得记住

>「为了实现这一点，Remedy 把 Northlight 里的 **Havok 物理换成了 PhysX**。」

以及控制设计的信条（可移植）：

>「超能力被设计成**直观**的：玩家**不需要手动瞄准环境**去拾取物体，
> 而抓起来的物体可以被甩出去，造成毁灭性伤害。」

★ **「不需要手动瞄准」是关键的手感设计**：抓取应该是「指向即抓」，
射线检测 + 视野内最近可抓物体，而不是玩家手动选。

## 五、★ 「能不能直接复制人家的地图」

分三层答，每层都要说清真实障碍在哪。

### 5.1 技术层面：资产能被提取，但不能直接用

| 障碍 | 说明 |
|---|---|
| **容器可解| 资产在 `.pak` 里，FModel / UAssetGUI 这类工具**能提取 mesh 和贴图** |
| **★ 但材质不能用** | Control 用 **RTX Mega Geometry**（硬件光追几何），着色器是 **NVIDIA RTX 专属路径**。Unity 没有对应管线 |
| **★ 地图打不开** | 地图是 `.umap`，Northlight 是**深度魔改过的 UE5**（Remedy 持有 UE 源码授权）。原版 UE 编辑器打不开，必须用 Northlight 版编辑器 |
| **提取 ≠ 能用** | 拿到网格不等于有美术管线。**UV/材质/碰撞/光照全要重做** |

### 5.2★ 折叠地图根本不是模型问题

UP 主已经说清了：

>「实现这样的地图结构，它不是简单的地编来拼接，或者说生成就能设计出来的东西，
> **需要巨量的人工去堆砌。每一个区域都有巨大的差异性，
> 每一个区域的核心探索逻辑也不同，承载的区域属性也不一样。」

→ **折叠是关卡设计，不是几何变换。** 地铁折叠成那个样子是**美术+设计**的结果，
不是把一段几何体旋转 90°。

### 5.3 ★ 成本量级

游戏是**多区域箱庭 + 每区手工差异化**。按区域数估：

| 范围 | 内容 |
|---|---|
| 单个箱庭区域 | 一栋楼 / 一个地铁站 / 一个公园的尺度，含隐藏遭遇、可选收集、环境叙事 |
| 每区独有 | 核心探索逻辑 + 区域属性 + 独特奇观 |
| 总量 | Remedy 用「历年最好的地图」形容，且是**多年多团队**产出 |

★ **对比本项目**：`HouseBlockout` 是**程序化生成**的一栋楼——
两者不是同一类东西。**能借鉴的是设计手法，不是产出量级。**

## 六、★ 对蜘蛛项目直接相关的一条：重力切换

蜘蛛跑酷与重力切换的契合度极高，原因在项目本身：

| 项目现状 | 重力切换需要什么 | 匹配情况 |
|---|---|---|
| Z-up 坐标系，**表面法线即「上」** | 一个可变的 `Vector3.up` | **已经是这个模型了** |
| 表面移动（`SilkSpiderSurfaceMove`）| 把 `forward` 换成「法线方向」 | 已有 |
| 蜘蛛可以**在任何表面**爬（墙、天花板、垂直面） | 玩家的「地板」=任意法线 | **天然适配** |
| 玩家是球，`visualRadius` 恒定 | 重力切换时球体行为不变 | 天然 |

★ **技术上「切换重力」在项目里就是换`Vector3.up` + 重算表面法线朝向**，
而蜘蛛的八足 FABRIK 不需要任何改动——它本来就是跟着法线走的。

**但要注意视频里那个最重要的警示**：

>「初次来到西部入侵区的前两个小时，眩晕感还是挺严重的……
> 我本身已经是非常不容易 3D 眩晕的人了，如果你本身就容易晕车、有3D 眩晕，
> 那么这个游戏对你来说简直是生理性的杀伤。」

★ **连「几乎不会 3D 眩晕的人」都晕了两个小时**。
这个机制不是纯增益，它自带一笔必要成本。
